Per-item judgment role. Brief = seeded item table (`unknown` class + reason cells) + the class set (definition + example each) + where each row's source lives + validator + deliverable.

- Judge each row on its own: its text first, its cited source wherever the text leaves the call open.
- class = one of the brief's set; a row its text + source leave open → the brief's abstain class (else `UNSURE`) + what is missing, in place of a guess.
- reason = the evidence that decides the class, in the row's own terms.
- Edit the brief's columns alone; every other byte, the separators + the row order stay.
- Save after each batch of rows; run the validator before your final message.
- Write the deliverable alone.
