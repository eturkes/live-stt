## Orientation

**What it is:** real-time Japanese STT + English translation, fully local STT, no API keys (D-009). Pipeline (all in `live_stt.py`, ~800 lines, single-file by D-002): mic → `resample` → silero VAD → `RingBuffer` pre-pad re-slice → sherpa-onnx decode (JA, k2v2 default) → `CodexTranslator` (JA→EN over a persistent `codex app-server`, JSON-RPC/stdio, D-011) → `emit_line`. Degrades to JA-only when codex is absent/failing (hard requirement, D-009).

**File map** (read a file only when the task implicates it):
- `live_stt.py` — the whole app. Edit minimally; its comments encode bench-derived optimization rationale — preserve them (L-001).
- `replay.py` — deterministic WAV → live-`worker` replay via the `on_segment` hook (D-014); the agent-verifiable regression path.
- `cer.py` — shared eval primitive (ROOT, sibling to replay): `normalize` (NFKC→casefold→drop Unicode P/S/Z/M) + `align`→(S,D,I) Levenshtein backtrace, documented tie order (diagonal-preferred → transpositions score as S, D not inflated). Pure stdlib. Used by `build_stressor` (T9.1) + the T9.2 CER harness/tests.
- `tests/` — `test_audio.py` (pure fns: resample/pcm16/emit/RingBuffer), `test_replay.py` (golden regression, skips without models/corpus), `test_translator.py` (CodexTranslator degradation locks: 3-strike disable, backlog evict, `_read_loop`/EOF — in-memory `StreamReader`+`FakeProc`, `asyncio.run` per test, no pytest-asyncio), `gen_replay_goldens.py` + `replay_goldens.json` (goldens), `fetch_real_clips.py` + `real_clips.json` (T5.3 corpus provenance), `build_stressor.py` + `stressor_clips.json` (T9.1 continuous-speech stressor: silero-trim CV singles → equal-power crossfade-join → `stress_{long,med}.wav` in cache; manifest = refs + recipe + per-component baseline D per engine). The pyright gate checks `live_stt.py replay.py cer.py` (explicit args), yet keep test files pyright-clean too (the LSP + a `--project . tests/` run flag them); house idiom for a fake→typed-attr assignment is `# type: ignore[assignment]` (cf. `State.stop_event`), and unused-param hints (`time_info`, `_ja`) are tolerated — basic mode, the CLI counts them 0.

`sounddevice` dlopens system PortAudio at import; without it import/pytest/hook fail `OSError: PortAudio library not found` → `sudo apt-get install libportaudio2` (Debian). Confirm native libs by importing the binding, not `ldconfig -p` (L-010).

Per-layer venvs (host = live-mic runtime, lowest latency; container = agent dev/test): committed `.envrc` (direnv, pose-estimation pattern) keys on path prefix — `/run/host/*` → `.venv` (container layer), else `.venv-host` (host layer) — plus `UV_LINK_MODE=copy` both layers (uv cache crosses filesystems; hardlink warning otherwise). Footgun both ways: agent non-interactive Bash INHERITS `UV_PROJECT_ENVIRONMENT=.venv-host` from the launch env (verified 2026-07-06; direnv is interactive-only + `.envrc` is deny-Read'd via the `.env*` glob, so neither corrects it) → a bare container `uv run` rebuilds `.venv-host` with container py, clobbering the host layer; conversely a host `uv run` (2026-07-02) re-baked `.venv` to `file:///home/eturkes/…`, container sync flipped it back → always pin `UV_PROJECT_ENVIRONMENT=.venv uv run …` (+`--no-sync` once synced) for container work. `.venv-host` is gitignored + deny-Read'd + pyright-excluded (materializes in-container via the shared tree; both layers currently resolve to the same uv-managed py3.14).

`rg` skips dotdirs by default, silently missing `.agent/` + `.claude/` (memory, roadmap, commands) — pass `--hidden --glob '!.git/**'` to search them.

**Do-not-read** (deny-listed in `.claude/settings.json`; off-limits via *every* tool, ask rather than probe — D-008): `.git/**`, `.venv/**`, `.env*`, `uv.lock`, `LICENSE`, `spike/backends/cache/**`, `.serena/{cache,memories,project.local.yml}`, `.tokensave/**` (regenerable code-graph state), `**/{__pycache__,.pytest_cache,.ruff_cache}/**`. A script's *runtime* `open()` of a deny-listed path still works — only the tool boundary blocks (L-016). Keep `.serena/project.yml` `ignored_paths` (`[uv.lock, LICENSE]`) in sync with non-gitignored deny entries (D-013).

**Style:** constants at the top of `live_stt.py` are the config surface; no frameworks/DI/config systems/back-compat shims (0.1.0, one user); comments explain *why*; module-level imports; default to inlining, three similar lines beat a premature abstraction (L-005); only edit code if you can name the failure mode it prevents (L-001); personal single-user tool (user directive 2026-07-02): performance is the bar — skip robustness/flexibility toward unpredictable users/use-cases.

**Known caveats:**
- Models are a runtime prerequisite — `check_models()` preflights and points at `models/README.md`.
- Silero opens segments 0.2–0.7 s late (D-010); every segment is re-sliced from the ring with `VAD_PRE_PAD_S=0.4` lead-in — VAD/worker edits must preserve this.
- Long segments (>~15–20 s of pause-less speech) degrade offline decode — wholesale deletions (L-023; D-010's "synthetic TTS collapse" was this length effect, amended 2026-07-02). Paused speech + per-sentence bench clips are unaffected.
- Tool-feature disables in `_CODEX_CONFIG` are THE latency lever (D-011): re-enabling web_search/browser/apps re-injects ~15 K tokens/turn (p50 0.99 s → 3.15 s) — keep them off.
- Codex auth is external state (`~/.codex/auth.json`, check existence only, never read); plan reports `prolite`, Spark entitled regardless (D-011).
- `sherpa-onnx` + `sherpa-onnx-core` (carries libonnxruntime) are both pinned — keep both (uv once skipped the declared sub-dep).
- Benign default-engine STT quirks: ジェミニ→ゼミニ, 文→分 homophone — EN leg translates through them.
- The EN leg needs `codex` on the PATH of the machine *running* live-stt; installs/logins are per-machine, user-only, and a container login does not carry over. Both layers have it now — host installed + EN confirmed live there (second smoke, 2026-07-02).

## Decisions (D-002 … D-014)

ADR-style, compact — active decisions only. When one is superseded, delete it and fold any still-live constraint into the successor; the prior record lives in git + `roadmap.md` + `SPIKE_REPORT*.md`.

- **D-002 — Single-file `live_stt.py`.** No package/module split: one dev (agent), one user; splitting buys reuse/isolation we don't need and costs context per file. Revisit past ~1000 lines (navigation cost may then exceed split cost).
- **D-004 — `.agent/` shape = the lean memory system.** Current shape: `memory.md` + `roadmap.md` + `context.sh`, all committed (a fresh clone reproduces full agent context per AGENTS.md's long-horizon rule). *Resist re-expanding into per-topic files — the single memory file is the decision.*
- **D-005 — Spike reports stay at repo root.** `SPIKE_REPORT*.md` are foundational decision records (the "why" behind the superseded Gemini backend); root-level keeps blame trails intact. Indexed from § Orientation. Revisit if >4 accumulate → `spike/reports/`.
- **D-006 — Don't refactor `live_stt.py` for "LLM-readability."** Its optimization comments encode irreplaceable rationale; denser naming saves ~30 tokens at every call-site's expense (L-001). Target a specific confusing line only on a real incident, never the whole file.
- **D-007 — Pre-commit hook via `.githooks/` + `core.hooksPath`, not the `pre-commit` framework.** The hook is one line (`uv run pytest -q`); the framework adds schema + per-hook venv cache + network bootstrap for nothing at this scope. Each clone opts in once (`git config --local core.hooksPath .githooks`). `--no-verify` bypasses for emergencies. Revisit if the hook grows past one or two commands.
- **D-008 — `.claude/settings.json` deny-list.** Denies the do-not-read set (see § Orientation) to keep secrets/bulk/regenerable paths out of context. Deny gates *every* tool including Bash — there is no escape hatch; ask the user instead of probing (amended after Bash refused deny-listed paths). A script's runtime `open()` is unaffected (L-016). Max-model/max-effort subagent env is enforced globally (`~/.claude/settings.json`), not per-project. Revisit a needed denied path by narrowing the rule.
- **D-009 — No-API-key architecture: local STT + Codex-subscription translation, Gemini replaced outright.** Trigger: user wants a Codex subscription, no API keys. Supersedes the Gemini backend (T3.1/T3.2, `SPIKE_REPORT.md`), kills T-BACKENDS-001. STT leg = local CPU-only streaming JA engine (D-010); translation leg = Codex subscription text surface via the sanctioned persistent CLI (D-011), chosen over the undocumented backend endpoint and over Codex `[realtime]` voice (agentic-loop-wrapped, 60 s-capped — unfit as a transcriber). Local MT rejected by user (wanted GPT-quality EN at zero marginal cost). Consequences: endpointing/VAD returns to the app (silero); new runtime dep on codex CLI + OAuth; **graceful JA-only degradation is a hard requirement**. Revisit if a subscription-auth realtime audio surface becomes sanctioned, or local CPU JA quality proves insufficient (try larger local models before any metered API).
- **D-010 — STT engine: reazonspeech-k2-v2 default, parakeet-ja A/B alternate (both via sherpa-onnx).** *(README/models/README cite this for engine-selection rationale.)* Measured (5 clips, 8-core CPU, int8-enc+fp32-dec for k2): both TTFT ≤0.10 s post-audio (Gemini baseline 1.21 s), $0/hr. Default **k2-v2**: RTF 0.054 vs 0.106, 148 MB vs 625 MB, Apache-2.0, JA-specialist, kanji-rich output. Keep **parakeet** selectable (slightly better published CER, wins the 文 homophone) — same sherpa integration, near-zero cost to retain. Two findings that shaped the live path: (1) **silero onset clipping** — segments open 0.2–0.7 s late, sherpa exposes no pad field → re-slice each segment from the fed-sample ring with `VAD_PRE_PAD_S=0.4`; (2) **long segments collapse decode** — amended 2026-07-02: originally read as "synthetic TTS collapses decode", but T9 planning showed the axis is segment LENGTH (>~15–20 s pause-less), not synthetic-vs-real (L-023; real continuous speech deletes the same way; each sentence fine in isolation). Revisit default-engine choice in T9.4 (parakeet materially more length-robust: excess deletion ≈8 % vs k2v2 ≈13 % at 36.5 s); also revisit if Reazon ships native-streaming JA or proper-noun drift proves disruptive.
- **D-011 — Translation leg: codex app-server, Spark + low effort, `developerInstructions`, tool features off.** *(README cites this for the translator's latency + injection-resistance.)* Surface: persistent `codex app-server` subprocess, newline-delimited JSON-RPC/stdio — `initialize` → `thread/start` (one thread/session, `ephemeral`, `sandbox:read-only`, `approvalPolicy:never`, `personality:none`) → `turn/start` per block → `agentMessage` deltas → `turn/completed`; quota via `account/rateLimits/read`. Four binding choices: (1) model `gpt-5.3-codex-spark` + `effort:low` (fallback `gpt-5.4-mini`+`none`, p50 1.18 s); (2) **disable tool-injecting features at spawn** (web_search/image/browser/computer/apps) — THE latency lever: tool schemas were ~15 K tokens/turn, p50 3.15 s → **0.99 s**; (3) role pinned via `developerInstructions` on thread/start — injection-resistant (imperatives in the speech get translated, not obeyed; AGENTS.md-in-cwd mode was rejected — Spark obeyed "delete all files"); (4) marginal cost ≈180 in + 7–60 out tokens/turn, ~50 turns moved the 5 h window ~0 %. Live notes: thread grows ~30 tok/turn → rotate every ~100 turns (one ~2.7 s uncached turn); `error` notifications with `willRetry` → degrade JA-only. Degradation guarantees (locked by `tests/test_translator.py`): a >64 KiB line, broken transport, or EOF routes into cleanup that enqueues one `{method:error}` sentinel onto `_notes` — a turn parked mid-collect then raises at once instead of waiting out `TRANSLATE_TIMEOUT_S`; the enabled→disabled flip logs once; `submit` counts backlog evictions into `dropped_translations` (meter `tdrop=`, >0 only). `start()` re-checks `_reader_task.done()`/`returncode` before enabling, so a warm-up death can't strand later turns over a dead reader (L-022). Revisit if Spark latency/entitlement changes, sustained quota burn contradicts ~0 %, or a leaner instructions channel is sanctioned.
- **D-012 — Bootstrap is the `/session-prompt [TASK]` slash command.** Lives at `.claude/commands/session-prompt.md` (native reusable-prompt mechanism; one `$ARGUMENTS` slot: blank → next open roadmap task, `<TASK>` → override). Loads `roadmap.md` → `memory.md` then acts (CLAUDE.md is always in-context). `/codex-review` is the second standing command — non-interactive adversarial Codex accountability. Slash-command registration is user-verifiable only. *Rule for future seed refreshes: adapt the command to the roadmap, never the roadmap to the seed's vocabulary.*
- **D-013 — `.serena/` tracking + scoped commits.** `.serena/` is committed as-is via its own nested `.serena/.gitignore` (ignores `cache/` + `project.local.yml`); Serena's memory system is disabled globally, so `memories/` stays empty and is left un-ignored by git but Read-denied (a deliberate do-not-read-but-not-gitignored split, CLAUDE.md-sanctioned). `.agent/` is the sole project memory store — avoid `mcp__serena__*_memory` tools. Keep three surfaces in sync: a new non-gitignored deny entry must also land in `.serena/project.yml` `ignored_paths` (`[uv.lock, LICENSE]`). End-of-turn commits use the scoped form (`Scope: summary` + co-author trailer); the trailer keys on who *ran* the commit, not who authored the content — an agent committing the user's own edit still carries it, only commits the user runs themselves carry none. *Do not re-oscillate the `memories/` ignore between root and nested gitignores — earlier sessions churned on this; current resolved state is "committed as is."*
- **D-014 — Deterministic WAV replay is the regression harness; bench harness retired.** `replay.py` drives the real `live_stt.worker` via an optional `on_segment` hook (live-mic path passes nothing → byte-for-byte unchanged) — chosen over freeze-and-reimplement precisely because a reimplemented loop is what drifted in the old `prototype_local.py`. Goldens are characterization snapshots in `tests/replay_goldens.json` (engine-first keying), asserting segment count + per-segment text + boundary (±0.1 s); CPU-variable decode latency is reported only. Coverage: replay covers resample→VAD→ring→decode→transcript + JA-only degradation; mic/device/latency-feel/Ctrl+C/soak/live-cadence stay user-only (§ Smoke). ## Lessons (L-001 … L-023)

Generalizable rules from past mistakes/findings — active only. Tests cite L-004, L-016. Delete a lesson once obsolete or folded into another; git holds it.

- **L-001 — Don't over-edit optimized code for "LLM-readability."** Keep comments that encode a non-obvious invariant/optimization and naming that's already domain-aligned; only edit when you can name a specific failure mode the edit prevents.
- **L-004 — Mic and real-terminal paths are agent-unverifiable.** The sandbox has no mic/interactive TTY. Any change touching `sd.InputStream`/`audio_callback`/real-time latency/Ctrl+C/multi-hour behavior gets a "**Did not verify**" list (see § Smoke) naming each path for the user; do not claim "done" without it.
- **L-005 — Avoid abstractions in `live_stt.py`.** Trajectory is consistently "less code wins"; default to inlining, no config/DI/plugins/class hierarchies unless the task requires them.
- **L-006 — TTY-aware `logging.Formatter` when stderr coexists with a live stdout UI.** Encode the cursor-clear (`\r\x1b[2K`) protocol in the Formatter, gated on `sys.stderr.isatty()` evaluated once, so call sites stay format-agnostic and redirected logs are ANSI-free. The rare case where a ~10-line subclass beats inlining (vs L-005).
- **L-008 — A single user preference is state, not an "always" rule.** Record placement/config choices as *current state* citing CLAUDE.md, not as `always`/`never` laws; ask before reversing a user-set arrangement. Reserve firm lessons for technically-derivable facts.
- **L-010 — Check a dlopen'd native lib by importing its binding, not `ldconfig -p`.** This container's `ld.so.cache` is empty yet libs resolve fine; use `uv run python -c "import sounddevice"` or `dpkg -l libportaudio2`.
- **L-016 — Deny-listed paths block on the command line, not on a script's runtime `open()`.** The deny-list acts at the Claude tool boundary (refuses the path in any Read/Edit/Bash target). A script that builds the path from components internally and `open()`s it at runtime reads fine. For an agent CLI smoke that can't name a deny-listed corpus, synthesize a throwaway file.
- **L-017 — Fetch a few real labeled HF samples via the datasets-server `/rows` API, not `load_dataset`.** Pick an ungated Parquet mirror, verify with `/splits`, read `…/rows?dataset=…&offset=N&length=≤100`; each row carries an expiring `audio[0].src` (fetch same-run); `soundfile` decodes MP3 (no ffmpeg). Sidesteps gating, loading-script breakage, multi-GB pulls.
- **L-018 — Maintenance-pass recipe.** Inventory `uv tree --outdated --depth 1` → CVE scan `uv export --format requirements-txt --all-groups --no-emit-project >/tmp/reqs.txt && uvx pip-audit -r /tmp/reqs.txt` (pip-audit scans its own env — feed it the export) → apply lock-only bumps (`uv lock --upgrade-package NAME`, leave pyproject floors) + full gate (import, pytest, ruff, `uvx pyright@1.1.410`) → re-verify the codex leg (not in pytest) via a synthetic `CodexTranslator` turn (`start()` warm-up + `_translate`). Keep package versions out of memory (drift risk).
- **L-019 — A refactor pass on mature, guarded code may correctly yield almost nothing.** Screen each candidate against L-001 ("name the failure mode prevented"); land only those with a nameable win or house-style fix, record the rejected ones in `roadmap.md` so they aren't re-litigated. "Mature; minimal change" is an honest result — don't manufacture edits (pink-elephant pull).
- **L-020 — Roadmap-generation via workflow: the adversarial screen is the deliverable, not the ideation.** Force every finder to read the real code/memory first (ungrounded agents propose out-of-scope textbook features); gate each candidate through a reviewer carrying the project's own laws; record rejects; report a small high-conviction list; verify the highest-stakes survivors against live code yourself and write tasks by symbol/behavior (line refs drift).
- **L-021 — AGENTS.md "hyphens over dashes" / de-LLM-smell applies to human-facing surfaces only.** Edit only `README.md` and the user-facing CLI strings in `live_stt.py`; leave `.agent/*`, `roadmap.md`, `AGENTS.md`/`CLAUDE.md`, code comments, and the Codex prompt (em-dashes deliberate there). Confirm with `grep -nP '[\x{2013}\x{2014}]' README.md`; keep any literal duplicated across code and README in sync.
- **L-022 — Adversarial-review follow-through: fix with a non-vacuous lock, and record the rejects.** Codex Finding 1 (HIGH) surfaced an "enable-over-corpse" startup race (a warm-up/health check that completes just before an async child dies can flip you "live" over a finished reader). Durable pattern: **validate liveness at the commit point** (re-check `_reader_task.done()`/`returncode` immediately before `enabled=True`), not only at spawn. Two reusable test techniques: (a) **deterministic async-EOF** — buffer every response line AND `feed_eof()` in one synchronous burst before the read loop drains; `StreamReader.readline()` returns without yielding when a line is already buffered, so EOF is guaranteed processed before the code under test reads liveness. Answer control requests reactively through `_read_loop` (`_await_pending(rid)` → feed the result line) rather than reaching past it with `set_result` — exercises the real dispatch path. (b) **Prove non-vacuity** — neutralize the fix (`if False and …`), watch the new test fail with the exact bug, restore. Record rejected findings with the reason so they are not re-litigated: Finding 2 (the EOF *cleanup* logs once; a rare second ERROR is `_translate`'s 3-strike branch — distinct, correct, already commented) and Finding 4 (`close()` runs only after `translator_task` ends, so no `_turn` is mid-collect — the no-sentinel claim is correctly scoped) were both rejected as code changes.

- **L-023 — Long continuous speech defeats soft caps and offline decoders; test with a genuinely-continuous stressor.** sherpa's silero `max_speech_duration` raises the threshold (0.5→0.9, min_silence→0.1 s) instead of hard-cutting — dip-less speech grows unboundedly, so VAD tuning alone cannot bound segment length. Offline attention/transducer models delete content wholesale past ~15 s (k2v2 at 36.5 s: 24 % raw, ≈13 % EXCESS over the stressor's own trim-artifact baseline — the honest headline; whole utterances vanish incl. a segment head; engine-dependent — parakeet ≈8 % excess). Segment LENGTH, not synthetic-vs-real audio, is the degradation axis (D-010's "TTS collapse" was this). Building a continuous stressor from real short clips requires silero-trimmed speech extents + ~10 ms crossfade joins — gap-concat leaves clip-edge quiet noise the VAD rightly reads as silence. The trim itself costs onset deletions on isolated decode (silero opens late; 0.4 s pre-pad recovers) → always record a per-component baseline and report EXCESS deletion, or the stressor measures its own construction artifact. Evidence + numbers: `roadmap.md` § Open (T9 planning block).

## Smoke checklist (agent cannot verify) — L-004

The live paths a sandboxed agent can't run: mic capture, device select, latency feel, Ctrl+C flush, `-o` persistence, multi-hour soak. This is the fixed procedure a "Did not verify (L-004)" disclaimer points at; each item names the `live_stt.py` observable that decides pass/fail. **Setup:** models downloaded; `codex login` once for the EN leg (without it: `Translation: unavailable — JA-only`, EN checks N/A). One utterance = speech + a ≥0.5 s pause (`VAD_MIN_SILENCE_S`).

**Live-mic pass (~5 min):**
1. **Devices** — `uv run live-stt --list-devices` lists the `sd.query_devices()` table and exits. Pass: your mic shows with input channels.
2. **Capture + meter** — `uv run live-stt`, speak. Pass: the bar rises with voice / falls in silence; no `drop=` and `q=` absent (brief `q=1–2` during a decode is fine; a standing `q=N` or any `drop=N` fails — audio_q drained).
3. **Device select** — `uv run live-stt --device N`. Pass: prints `Mic: #N <name> @ <rate> Hz`; meter reacts as in (2).
4. **Latency + endpointing** — one sentence, then stop. Pass: `JA n:` prints ~0.6 s after you stop (0.5 s `VAD_MIN_SILENCE_S` + ~0.1 s decode, D-010); a brief mid-sentence pause does not split it.
5. **Translation cadence** — Codex up. Pass: each `EN n:` trails its `JA n:` by ~1 s, shared `n` keeps pairs matched; `--no-translate` suppresses every EN line.
6. **Ctrl+C mid-utterance** — start speaking, Ctrl+C while still talking. Pass: the in-progress `JA n:` still prints (worker flushes the VAD in `finally`), its `EN n:` still lands if Codex is up (translator drains last), then `Stopped.` with no hang (non-blocking shutdown sentinel, T8.1).
7. **`-o` persistence** — `uv run live-stt -o /tmp/stt.txt`, speak, Ctrl+C. Pass: file holds `[<ISO-8601>] JA n: …` / `EN n: …` lines, one per event, flushed immediately, closed in `finally`.

**Soak (1–3 h)** — watch the three in-code observables at start and end:
- **Backlog/drops** — meter `q=` stays absent (or blips and clears), `drop=` never appears. A standing `q=N`/`drop=N` means decode fell behind the mic (audio_q hit `AUDIO_QUEUE_MAX`=100).
- **Thread rotation** — ~every 100 EN turns one `EN` lands a few seconds slower then cadence resumes with no error (codex thread rotation, D-011); EN must keep flowing across the bump.
- **Quota** — out-of-band via `account/rateLimits/read` (not surfaced in-app); expect ≈0 % primary-window movement (D-011). A climbing window → revisit D-011.
- **Memory** (external `ps`/`top`): RSS flat — ring is fixed (`RING_SECONDS`), `_RESAMPLE_CACHE`≤8, codex `_notes`/`_pending` drain per turn; steady growth signals a leak.

EN stopping while JA continues is the D-009 JA-only degrade: the 3-consecutive-failure path logs `translation disabled after N…`; a codex EOF in an idle gap logs `codex app-server exited; JA-only…` once and, if a turn is mid-flight, wakes it promptly instead of stalling a window.
