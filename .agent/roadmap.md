Canonical plan + status. Pick the lowest-numbered OPEN unit; restate its acceptance criteria before coding. Trajectory: single-file tool, simplicity over completeness — no frameworks, no config, no premature abstraction. Milestone states: UNPLANNED · IN-PROGRESS · IMPLEMENTED · REVIEWED · PARKED (skipped by MODE dispatch; the entry names its re-entry precondition, and meeting it + clearing the marker returns the milestone to the active-milestone scan). Unit states: OPEN · BLOCKED · DONE. Ledger dispositions: DEFERRED · SUPERSEDED · OUT-OF-SCOPE · REJECTED. Context records = `context-gauge` readings (machine tool, `~/.local/bin`), `N% NK/240K`: `harvest=` = MAIN as implementation starts (the dominant pre-implementation term), `main=` = MAIN at close, which carries implementation, and `mate=` = peak teammate high-water; a unit closed at the context reserve records that overrun beside `main=` so PLANNING sizes against the real cost. Planning records each unit's size as `est <raw>K → <cal>K` = the bottom-up figure and that figure times the milestone's measured `main=`/`est` ratio, so corrections live in the multiplier. Historical `impl=` = peak implementing teammate under the superseded delegated-implementation model ≈ implementation load, so PLANNING sizes a unit against the nearest analog's `main=` or `impl=` (M10.5a–d predate teammate resolution and record final-turn values, which understate peaks). Units carry `tier=kernel|data|docs` from planning; units planned without one default to `kernel`. A REVIEWED milestone keeps one summary here — status, commit range, shipped surface, gauge band, archive pointer — while its unit detail moves to the named `.agent/archive/<record>.md`, outside the attached set and read on demand. Two more committed locations sit outside that set: `.agent/contracts/` = the dispatch inputs a later mode reads — each unit's acceptance contract (`m<m>u<u>.md`), its fixed check sets and verdict tables (`m<m>u<u>-rev*.md`), and the anchored surface maps a unit is told to read instead of re-deriving (`*-map-<k>.md`) — and `.agent/review-m<m>.md` = that mode's row ledger, which gates REVIEWED and resumes across sessions. `.scratch/` is gitignored, so an artifact a later mode dispatches from is committed to `.agent/contracts/` when its unit closes.
