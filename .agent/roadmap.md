# Roadmap — live-stt

Canonical plan + status. Pick the lowest-numbered OPEN unit; restate its acceptance criteria before coding. Trajectory: single-file tool, simplicity over completeness — no frameworks, no config, no premature abstraction. Milestone states: UNPLANNED · IN-PROGRESS · IMPLEMENTED · REVIEWED. Unit states: OPEN · BLOCKED · DONE. Ledger dispositions: DEFERRED · SUPERSEDED · OUT-OF-SCOPE · REJECTED. Context records = `.agent/context-gauge.sh` readings, `N% NK/240K`: `main=` = MAIN, which now carries implementation, and `mate=` = peak teammate high-water. Historical `impl=` = peak implementing teammate under the superseded delegated-implementation model ≈ implementation load, so PLANNING sizes a unit against the nearest analog's `main=` or `impl=` (M10.5a–d predate teammate resolution and record final-turn values, which understate peaks). Units carry `tier=kernel|data|docs` from planning; units planned without one default to `kernel`.
