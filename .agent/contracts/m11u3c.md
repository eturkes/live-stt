# M11.3c — Whisper/VAC replay golden · acceptance contract

`tier=kernel`. Base SHA `cd8e86f`. Gate identity = `gate.py` (7 blocking steps, stays 7/7).

## Problem

`tests/gen_replay_goldens.py` builds `ENGINES × all_clips()` = a Cartesian product. Adding `whisper`
to `ENGINES` would produce 12 whisper rows: ~2 min of NPU decode per regeneration, 12 accelerator-bound
rows to review, for a path whose per-clip marginal information is low. The committed golden matrix is
therefore sherpa-only (24 rows), and the shipped default engine has **no replay regression at all**.

## Decisions (evidence-backed, from MAIN's probes at `cd8e86f`)

- **D-A · The whisper row covers `long`, not `greet`.** Roadmap named `greet` as the determinism clip.
  Measured VAC depth per clip (probe counts `StreamingProcessor.process` calls and `emitted` growth):
  `greet` = 1 process call / **0 committed chars** — every character comes from the speech-end flush, so
  LocalAgreement-2 commits nothing and the row regression-tests almost none of VAC. `long` = 13 process
  calls / 51 committed chars / 2 utterances, the deepest of the five probed (`medium` 7/21, `cv_multi`
  6/25, `cv_xlong` 7/38). One row buys the most VAC surface at `long`.
- **D-B · Device gating is `available_devices`, not `check_models`.** Without the accel farm sourced,
  `openvino.Core().available_devices == ['CPU']` — `ASR_DEVICE`="NPU" is simply absent. `check_models`
  only stats a marker file, so it returns None on this box and would let the test construct a
  `WhisperPipeline` that **aborts** on the missing NPU compiler loader. `gate.py` sources no farm, so the
  readiness predicate must probe the device or the gate goes red.
- **D-C · The whisper row is device-bound and records its device.** Sherpa rows are CPU-deterministic and
  portable; the whisper row is an `ASR_DEVICE` artifact. The row carries `"device"`, and a mismatch
  against `live_stt.ASR_DEVICE` **fails** (regenerate) rather than skipping.
- **D-D · Regeneration preserves matrix rows it could not run.** `main()` currently rebuilds `out` from
  scratch and overwrites, so one farm-less run would silently delete the committed whisper row. Rows in
  the matrix that were skipped carry forward from the existing file; rows absent from the matrix are
  dropped. Every carried-forward and dropped row prints.
- **D-E · Determinism is a claim about `(clip, engine, device)`, never about whisper generally.**
  `replay.py`'s docstring already scopes the determinism claim to the sherpa engines. It gains the
  measured whisper scope instead of a blanket claim.

## Acceptance predicates (testable; every one decides pass/fail)

- **P1** `tests/replay_goldens.json` holds exactly **25** rows: the 24 sherpa rows **byte-identical** to
  `cd8e86f`, plus one `whisper`/`long` row.
- **P2** The whisper row regenerates **byte-identically** in two independent processes with the farm
  sourced. Evidence = two generator runs + `cmp` on the row projection.
- **P3** No timing field enters any golden or any comparison: the row carries `n_segments` and per-segment
  `start`/`n`/`text` only (plus `ja_ref`/`purpose`/`device` metadata). `decode_s`, `rtf`, `seg_len`,
  `total_decode_s`, `overall_rtf` appear nowhere in `replay_goldens.json`.
- **P4** The engine × clip matrix is **explicit**: whisper's clip list is a named constant, not derived
  from `all_clips()`. Adding a whisper clip is a one-token edit; no Cartesian product remains.
- **P5** The whisper golden test **skips** — never errors, never fails — when `ASR_DEVICE` is not in
  `openvino.Core().available_devices`, when `openvino` is unimportable, when the model marker is absent,
  or when the cached WAV is absent. Proof: `python gate.py` is 7/7 with **no farm sourced**.
- **P6** With the farm sourced, the whisper golden test **runs and passes** against the committed row.
- **P7** A whisper row whose `device` differs from `live_stt.ASR_DEVICE` **fails** with a regenerate
  message; it does not skip and does not compare.
- **P8** Regeneration restricted to sherpa (farm absent) leaves the committed whisper row intact in the
  written file, and says so on stderr.
- **P9** A matrix cell with no existing row and no ability to run is omitted with a warning; a golden row
  for an engine/clip **outside** the matrix is dropped by regeneration.
- **P10** `gate.py` stays 7 blocking steps; `tests/test_gate.py`'s inventory is unchanged.
- **P11** Sherpa golden behaviour is unchanged: `test_replay_golden` still parametrizes over every row and
  still skips per-row on absent models/WAVs.
