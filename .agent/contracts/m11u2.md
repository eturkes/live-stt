# M11.2 acceptance contract — shipped-path unit coverage

Unit `tier=kernel`. Deliverable = committed tests closing the roadmap's untested-surface list for the
shipped whisper+VAC+NPU path. MAIN authors every test (judgment-bearing). Production code changes only
where a surface is untestable without one, and each such change is named + justified.

Hard constraint (roadmap, verbatim): **no test requires a microphone, a model download, or a working
OpenVINO install.** `openvino`/`openvino-genai` are hard deps since M11.1 so the module imports, but no
test may construct a real `WhisperPipeline`, touch `/dev/accel*`, or need `models/`.

## Predicates

| P | Surface | Predicate |
|---|---|---|
| P1 | engine/device routing (`live_stt.py:362-383`, `:46-61`) | `load_recognizer(e, dev)` sends `e in WHISPER_ENGINES` to `WhisperEngine(ENGINE_DIRS[e], dev)` and every other `ENGINE_DIRS` key to a sherpa constructor reading that engine's own directory. `main()` `--engine` default = `"whisper"`, choices = `sorted(ENGINE_DIRS)`; `--asr-device` default = `ASR_DEVICE`. |
| P2 | `WhisperEngine` (`:307-359`) | Construction passes `str(model_dir)`, the device, and `CACHE_DIR=str(OPENVINO_CACHE_DIR)`, and creates the cache dir. `supports_hotwords == (device in ASR_HOTWORDS_DEVICES)`. `set_hotwords` stores the list on a capable device and stores `""` on an incapable one. `generate` always passes `language="<|ja|>"`, `task="transcribe"`, the requested `return_timestamps`, and passes `hotwords` **only** when non-empty. `decode` = joined+stripped texts. `decode_segments` returns spans, and returns `[]` spans when the concatenated segment text does not equal the transcript. |
| P3 | NPU hotword drop → empty `biased` (`:1150-1160`, `:1136-1139`) | At speech-open with a context and a `set_hotwords`-capable recogniser, `biased` = the offered term set when `rec.hotwords` is truthy after the set, else `frozenset()`. `context.observe_ja(utterance, biased)` receives exactly that set, so a dropped list makes the sighting count as un-prompted support. |
| P4 | `check_models` marker (`:462-479`) | Marker = `openvino_encoder_model.xml` for `WHISPER_ENGINES`, `tokens.txt` otherwise, resolved under `ENGINE_DIRS[engine]`. Missing VAD and/or missing marker each name their item in the message; both present returns `None`. |
| P5 | status-line partials (`:1229-1255`, `:1124-1128`) | Off-TTY `meter` returns without writing anything. On-TTY it emits `_LINE_CLEAR`, then the nonzero-only counters, then `state.partial` tail-truncated to the remaining terminal width; an empty `partial` adds no separator. `_vac_segments` sets `state.partial` to the running utterance on each commit and clears it to `""` at finalize. |
| P6 | `worker` duck dispatch (`:1198-1226`) | `hasattr(rec, "decode_segments")` routes to `_vac_segments` and never creates segment-queue work; a recogniser without it runs the `_feed_segments`/`_decode_segments` TaskGroup. |
| P7 | exactly-once publication (`:1133-1143`, `:1209-1213`) | One utterance produces exactly one `emit_line("JA", seq, text)`, exactly one `translator.submit(seq, text)` and exactly one `context.observe_ja(text, biased)`, all carrying the same `seq` and the same text. Intermediate `update(final=False)` ticks publish nothing. `seq` advances only on a published utterance; an utterance whose text is empty publishes nothing yet still fires `on_segment` once. |

## Mutation acceptance (each must fail >=1 committed test)

| M | Mutation | Kind |
|---|---|---|
| M1 | `--engine` default `"whisper"` -> `"k2v2"` | default engine string |
| M2 | `ASR_DEVICE` `"NPU"` -> `"CPU"` | default device |
| M3 | `ASR_HOTWORDS_DEVICES` gains `"NPU"` | hotword-capable device set |
| M4 | whisper marker `openvino_encoder_model.xml` -> another filename | marker filename |
| M5 | duck predicate `hasattr(rec, "decode_segments")` -> `hasattr(rec, "decode")` | duck-dispatch predicate |

Behavior-level, not literal echoes: a test that merely re-asserts the constant's spelling does not
count. Each mutation must break an assertion about what the code *does* with the value.
