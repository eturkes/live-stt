## Acceptance predicates

### P1 — VAC contract fingerprint, rooted separately from the sherpa hash

- **P1.1** `VAC_CONTRACT_ROOTS` = exactly `ASR_DEVICE`, `VAC_CHUNK_S`, `VAC_TRIM_S`, `WHISPER_ENGINES`,
  `WhisperEngine`, `_vac_segments`, `OPENVINO_CACHE_DIR`, all rooted in `live_stt`.
- **P1.2** The closure is **qualified** (`module`, `name`) and follows `ImportFrom` edges, so it spans
  `live_stt.py` **and** `streaming.py`; it contains `streaming.StreamingProcessor` and `streaming.Segment`.
- **P1.3** An edit to a VAC surface moves `vac_contract_sha256` — proved on `streaming.py`
  (`HARD_TRIM_S`) and on a `live_stt` VAC constant.
- **P1.4** An edit to a sherpa-only surface **holds** `vac_contract_sha256` — proved on
  `live_stt.DECODE_CHUNK_S`.
- **P1.5** `asr_contract_sha256` is **frozen** across this unit:
  `sha256(asr_contract_source()) == aff253181730b72354ca34042b18d1cc1e54f0b1f7931c1721d599f91c2192ed`,
  `len(ASR_CONTRACT_SEEDS) == 20`, `len(ASR_CONTRACT_CUTS) == 17`, `len(asr_contract_closure()) == 25`.
  Rationale (L-030, map A8): the sherpa hash is deliberately the offline-row contract; dissolving its
  cuts into one hash recreates the false-refusal class `d936cbe` fixed.
- **P1.6** Hashing is docstring-stripped `ast.dump`, so a comment/docstring/`ruff format` rewrap is
  inert while every executed expression moves the hash.
- **P1.7** A root or reached dependency that does not exist raises; it is never silently dropped.

### P2 — Schema + row identity

- **P2.1** `VAC_SCHEMA_VERSION` is the VAC evaluator's own version, independent of
  `eval_models.SCHEMA_VERSION`; `eval_streaming`'s event/accounting contract is not reused (map A2).
- **P2.2** Canonical row identity = `arm_id/corpus_id`; the case list is ordered **arm-major** and
  validated as an exact ordered set — a duplicate `row_id` raises.
- **P2.3** Row rejection is structural and exhaustive: non-dict row, `row_id` mismatched against the
  case at that index, wrong `schema_version`, missing required field, non-finite / negative /
  `bool`-typed measurement, and `wall_seconds < decode_seconds` each reject.
- **P2.4** Deterministic content and measured timing are separate journals; the manifest publishes
  timing under a sibling marked `excluded_from_deterministic_equality=true`.

### P3 — Automatic resume (no `--resume` flag exists)

- **P3.1** Resume identity mismatch resets every artifact (detail, both `.part` journals, state).
  Identity includes `schema_version`, the ordered `row_id` list, and `vac_contract_sha256`.
- **P3.2** A truncated final line (interrupted append) reconciles to the last complete row.
- **P3.3** A crash **between paired fsyncs** (detail = N+1 rows, measurements = N) reconciles to N and
  re-decodes exactly one row.
- **P3.4** A complete prior run reuses every row and re-decodes zero; `rows_reused_on_resume` reports it.
- **P3.5** A structurally invalid row mid-prefix truncates from that row onward.
- **P3.6** Detail reaches stable storage before its measurement (write→flush→fsync each, detail first).

### P4 — Detail install + atomic aggregate

- **P4.1** Details install content-addressed as `<arm_id>-<sha256[:16]>.jsonl`; a staged file whose
  hash changed before install raises.
- **P4.2** An existing destination with a different hash raises (collision); an identical hash is a
  no-op re-install.
- **P4.3** All validation precedes any write, and the aggregate is written **last** through
  `write_atomic`, so an interruption can only leave an unreferenced immutable detail — never a torn
  or partially-referenced baseline.

### P5 — `--aggregate-only`

- **P5.1** Rebuilds the baseline **byte-identically twice** from cached details on the synthetic corpus.
- **P5.2** Refuses when the recorded `vac_contract_sha256` differs from the current one.
- **P5.3** Refuses when a referenced detail is missing or its hash does not match the manifest.

### P6 — CLI surface (house contract, map A5)

- **P6.1** Public surface = default full run + `--aggregate-only`. `--worker`, `--details`, `--summary`
  are `argparse.SUPPRESS`.
- **P6.2** `--worker` with `--aggregate-only` errors; `--worker` requires both `--details` and
  `--summary`; bare `--details`/`--summary` without `--worker` errors.
- **P6.3** No `--out`, no cache-dir flag, no corpus-path flag, no `--resume`. Corpora and arms are
  committed constants; resume is implicit.

### P7 — Hardware independence + gate identity

- **P7.1** The whole suite runs with no `models/`, no OpenVINO, no NPU farm, and no `.scratch/` tree.
- **P7.2** `gate.py` stays **7/7 blocking**; `tests/test_eval_vac.py` runs inside the existing pytest
  step; `ruff`, `ruff format` and both pyright passes stay clean.

## Probe-corpus seed

Synthetic corpus = 2 arms × 3 corpora = 6 rows, arm-major (`arm-a/corpus-1` … `arm-b/corpus-3`).
Content is a deterministic function of the case, supplied either by the fake decode callable or by
the real `WhisperEngine`/`_vac_segments` over the fake binding, whose `generate()` returns text as a
function of sample count (scout probe `probe_s1`, 3 rows green).

## Ruling record

- **R-1 — arm decoder wiring.** The kernel resolves an arm's decoder through a registry; the one
  shipped arm calls production `replay.replay_recognizer(...)` (map A3: production replay is
  authoritative, no copied scratch policy). M11.3d adds comparator arms + metrics. A stub decoder
  would be a placeholder and is rejected.
- **R-2 — where the walker lives.** In `tests/eval_models.py`, the existing shared module
  (`eval_streaming.py` already does `import eval_models as shared`). One walker serving both contracts
  is what makes P1.5 provable by construction rather than by a parallel reimplementation.
