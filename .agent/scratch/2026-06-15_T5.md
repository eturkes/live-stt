**Goal:** make the local STT pipeline (VAD + RingBuffer + sherpa decode) regression-testable
by replaying WAVs through the **exact production loop** (`live_stt.worker`), not a copy.
No new app features; live-mic path behavior unchanged.

## Design

### worker() hook (live_stt.py)
```
async def worker(rec, vad, window, audio_q, state, output_file, translator=None, on_segment=None):
    ...
    while not vad.empty():
        start = int(vad.front.start); n = len(vad.front.samples); vad.pop()
        seg = ring.slice(start - pad, start + n)
        t_dec = time.perf_counter() if on_segment is not None else 0.0
        text = await loop.run_in_executor(None, _decode, rec, seg)
        if text: seq += 1; emit_line(...); translator.submit(...)
        if on_segment is not None:
            on_segment(start, n, len(seg), time.perf_counter() - t_dec, text)
```
- Fires for **every** popped segment (incl. empty-text) → segmentation fidelity.
- `seq`/emit/translator semantics untouched. Adds `import time`. ~5 lines, all guarded.

### replay.py (repo root; dev tool, NOT packaged)
- `load_wav_f32_16k(path) -> np.ndarray`: wave.open → float32 mono; resample via
  **`live_stt.resample`** (production resampler) to `SAMPLE_RATE`. Reuses the real path.
- Driver: `asyncio.run`; build real `rec=load_recognizer`, `vad,window=make_vad`; push whole
  float32 array as ONE chunk into an `asyncio.Queue` then `None`; run real `worker(..., translator=None,
  output_file=None, on_segment=collector)`; collect per-segment rows.
- Report (human table + `--json`): idx, start_s, end_s, dur_s, decode_s, RTF, text; totals
  (n_segments, n_nonempty, audio_s, decode_s, overall RTF).
- CLI: `uv run python replay.py WAV [--engine k2v2|parakeet] [--json]`.
- Ported clip refs (id/ja_ref/purpose) from scenarios.py for the cached-corpus path.

### Determinism / goldens
- **Deterministic** (asserted): n_segments, per-segment text, per-segment `start` (±window tol).
- **Non-deterministic** (report-only, never asserted): decode_s, RTF (CPU-variable).
- `tests/replay_goldens.json` (tracked) = {clip_id: {n_segments, segments:[{start,n,text}]}}.
  Generated this session from the real pipeline (models present). Characterization/golden-master:
  expected = current real output (engines have stable known quirks — D-010: 文→分, ジェミニ→ゼミニ),
  NOT idealized ja_ref.

### tests/test_replay.py (minimal)
- `test_load_wav_*`: synthetic WAV → tmp_path, assert float32/16k/mono + resample length.
  **Model-independent**, always runs.
- `test_replay_goldens`: model+cache-gated; per clip assert n_segments + text exact + start±tol.
  `pytest.skip` when models or cache WAVs absent (fresh clones).

## Coverage split (the deliverable)
- **Agent-verifiable now (replay covers):** WAV→resample→VAD segmentation→RingBuffer pre-pad
  re-slice→sherpa decode→transcript; per-segment decode latency/RTF; JA-only degradation (no translator).
- **User-only smoke (replay cannot cover):** mic capture / `sd.InputStream` / `audio_callback` /
  `call_soon_threadsafe`; device enum/selection; real-time latency feel + VAD endpointing on live
  speech; Ctrl+C/signal mid-utterance flush + drain; multi-hour quota/thread-rotation; live Codex
  cadence. (Codex leg correctness itself is separately agent-verifiable via synthetic turns.)
