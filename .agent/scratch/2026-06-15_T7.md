  the tuple was redundant and misleading beside the *necessary* lookalikes

  (`CancelledError ⊄ Exception`, so those must list both). Provably inert.

  replacing 3 bare `10`s (initialize; thread/start at startup; thread/start at
  rotation). Matches the existing `TRANSLATE_TIMEOUT_S` convention ("constants at
  top = config surface"). One use site crossed 100 cols → wrapped. Inert.
- **C2** — removed `meter()`'s 8-line global→local hoisting. The meter loop runs at
  10 Hz (`METER_INTERVAL=0.1`), where the local-vs-global lookup saving is
  irrelevant, and unlike the genuine hot-path opts (audio_callback dot-product,
  resample cache) it carried no explaining comment. Logic-identical output.

  best-effort (one retry, then drop a caption) while `submit_sentinel` must loop
  until the shutdown sentinel lands. A shared helper needs a `must_succeed` flag =
  an abstraction (L-005) that hides a deliberate semantic split. Keep separate.

  and `test_replay._write_wav` vs `fetch_real_clips.write_wav` — different input
  formats (wave vs soundfile/MP3) and sources (file vs URL); shared tail is ~3-5
  lines. Extraction adds a cross-module edge between a dev tool and the test/replay
  layer for negligible savings.
- **Centralize the triplicated `CACHE = ROOT/"spike"/"backends"/"cache"`** (gen,
  test, fetch) — harmless; each is constructed internally per L-016; a shared
  module is ~neutral on lines and adds a dependency edge.
- **Prune overlapping resample tests** (`halving` ⊂ `integer_decimation_32k`;
  `dtype_preserved` overlap) — removing working tests for trivial line savings loses
  named cases and risks its own over-correction; CLAUDE.md tolerates tests that give
  a useful feedback loop.
